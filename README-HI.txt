GK MOCK TEST - ANDROID APP PROJECT

यह Android Studio project है। ऐप प्रश्न बैंक और HTML/CSS/JS को APK के अंदर assets में रखता है, इसलिए टेस्ट बिना इंटरनेट भी चलते हैं।

APK बनाने के लिए:
1. Android Studio में यह folder खोलें।
2. Gradle Sync पूरा होने दें (पहली बार Android Gradle Plugin/SDK डाउनलोड हो सकता है)।
3. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
4. APK app/build/outputs/apk/debug/app-debug.apk में मिलेगा।

Package: in.gkmock.rrbssc
Minimum Android: 6.0 (API 23)

नोट: इस build environment में Android SDK/Gradle उपलब्ध नहीं है, इसलिए यहां से signed/compiled APK बनाना संभव नहीं हुआ। यह पूरा source project है; Android Studio से APK compile किया जा सकता है।
